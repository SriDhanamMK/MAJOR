The redesigned architecture illustrates the following stages:



1\. Source-code input for the supported programming languages: C, C++, and Python.

2\. Language-specific parsing through parser adapters.

3\. Conversion into a common abstract syntax tree representation.

4\. AST normalization, including formatting, identifier, and literal normalization.

5\. Dependency-informed statement reordering.

6\. Tree edit distance computation using the Zhang–Shasha algorithm.

7\. Similarity score calculation and result reporting.



The redesigned figure aims to make the relationship between the individual processing components easier to understand and to provide a clearer overview of the proposed framework.
